# Knowledge folder

The avatar answers questions from the Markdown pages in this folder (System 2).
It only rephrases what these pages say; if nothing here matches a question, it
says it doesn't know yet, and the question shows up in the conversation log.

- One topic per file, e.g. `about-me.md`, `devoteam.md`, `projects.md`.
- Use headings (`#`, `##`) to split a page into sections; each section is
  retrieved on its own, so keep a section about one thing.
- Write plain facts in full sentences, in English or Dutch; the avatar answers in
  English either way.
- Changes are picked up on the next question; no restart needed.
- Files starting with `_` and this README are not used. Copy `_template.md` to
  start a new page.
